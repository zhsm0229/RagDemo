# 01: 难例采集入池

**What to build:** 真实用户在问答中遇到的拒答问题与点踩回答，自动沉淀进难例种子池（hardcase_seeds），作为后续评测题合成的素材。任务体是可手动调用的纯函数（session/clock 注入），本票不挂 cron（调度装配在 05 票）。验收方式：造拒答/点踩消息 → 跑任务体 → 池中出现状态正确的行（读回断言）。

**Blocked by:** None (can start immediately)
