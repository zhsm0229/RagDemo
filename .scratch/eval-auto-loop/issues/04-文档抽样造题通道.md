# 04: 文档抽样造题通道（零召回块优先）

**What to build:** 系统从已入库文档中抽样知识块，自动生成正向评测题（1 问 1 答，回填 source_doc_id）入扩充集（origin=doc_synth, tier=extended）。零召回块优先抽样——它们正是"入库后从未被问到"的覆盖盲区，与"知识库实际使用场景"互补。

**Blocked by:** 02（题库来源/层级与升格）

**Status:** done（2026-10-30 完成，TDD 全绿）

- [x] 抽样口径：每部门每周 ≤M 块（配置 eval_auto_doc_sample_per_dept，缺省 20）；零召回块（last_hit_at IS NULL 或早于 30 天）优先，不足再补活跃块；只取 ready+is_active 文档的块（与概览零召回口径同源）
- [x] 造题：从块原文生成 1 问 1 答（答案必须能在块原文找到依据——prompt 约束 + 长度闸）；块原文过短（<100 字清洗后口径）跳过
- [x] 去重：与题库现有题、本批产物归一去重；同文档已造过题的块去重（source_doc_id+块 id 记录在 source_ref）
