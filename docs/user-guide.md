# 企业智能工作台 用户手册（试点版）

本手册面向客服、人力双部门试点，覆盖员工日常问答与管理员知识库运营的全部操作。文中**加粗**字样均为界面上的按钮、菜单、列名或提示原文；【截图：…】为截图占位符，内测时补充。术语与系统界面保持一致：知识库、文档、问答对、引用、评测、点踩、部门、预检、健康度、零召回、阈值扫描、到期日期，不使用同义替代。

---

## 第一篇 员工篇

> 本篇面向试点部门的全体员工，介绍登录、提问、核对引用与反馈的日常操作。

### 1. 登录与首次登录改密

【截图：登录页】

1. 打开工作台地址，进入登录页（标题"企业智能工作台"，副标题"基于企业知识库的智能问答 · 内部系统"）。
2. 输入**用户名**与**密码**（由管理员发放），点击**登 录**。
3. 首次登录会自动跳转到"首次登录请修改密码"页，必须先改密：输入**原密码**、**新密码**（至少 8 位）、**确认密码**，点击**确认修改并进入**。
4. 修改成功后提示"密码修改成功"，自动进入智能问答页。以后可在改密页（标题"修改密码"）自助改密，按钮为**确认修改**。

> 密码规则：至少 8 位。连续输错密码会触发账号锁定（见第三篇常见问题）。

【截图：首次登录请修改密码】

### 2. 提问与流式回答

【截图：智能问答页】

1. 左栏选中或新建会话（见第 7 节），中间输入框输入问题（占位提示"输入问题（1-2000 字），Enter 发送 / Shift+Enter 换行"）。
2. 按 **Enter** 发送（Shift+Enter 换行；中文输入法选词回车不会误发送）；也可点击**发送**按钮。右下角计数器实时显示字数（如 `36/2000`）。
3. 回答逐字流式输出。生成期间输入框上方出现**停止**按钮，点击可中止生成，气泡会标注"已停止"，可重新提问。
4. 若气泡下方出现红色"生成失败"及原因，点**重试**即可重新生成。
5. 每位用户每日有提问次数上限（默认 200 次），达到上限当天无法继续提问，次日自动恢复。

### 3. 引用角标与原文查看

系统每条回答都基于知识库内容生成，正文中的 `[1]` `[2]` 角标对应右侧**引用来源**面板中的卡片：

1. 点击回答中的角标，右侧对应引用卡片高亮并滚动定位。
2. 引用卡片显示 `[n] 标题`、来源类型（"问答对"或"文档块"）、标题路径、相似度与页码。
3. 点击引用卡片，打开"引用原文核对"弹窗：展示该引用的完整原文（只读，可选中复制），以及"页码/来源、位置、相似度"，供逐字核对回答是否与原文一致。
4. 引用面板可点**收起**折叠；收起后通过"引用面板"链接恢复。

【截图：引用来源面板】【截图：引用原文核对弹窗】

### 4. 拒答的含义（请务必了解）

当知识库中没有与问题相关的内容时，系统会回答固定话术：**"知识库中未找到相关内容"**，气泡下方标注"已拒答"，且不带引用。

**知识不足时拒答是为了不编造，这不是故障。** 系统被约束为"只依据知识库回答"，宁可拒答也不猜测。遇到拒答你可以：

1. 换个问法再问一次（例如把口语化表述换成文档中的规范说法）；
2. 确认该问题属于本部门知识范围（客服 / 人力 / 全员）；
3. 若知识库确实缺失，反馈管理员补充文档或问答对。

### 5. 点赞与点踩反馈

每条回答下方有 👍 / 👎 反馈入口（拒答回答与生成中断的消息不可反馈）：

1. **点赞**：点击 👍 即提交，提示"已点赞"，无弹窗。
2. **点踩**：点击 👎 打开"反馈问题（点踩）"弹窗：
   - **分类**必选：答案错误 / 引用无关 / 拒答不当 / 其他；
   - **备注**必填（1-500 字），占位提示"请描述问题，帮助定位 badcase"——分类和备注缺一不可，这是管理员定位问题的唯一线索；
   - 点击**提交反馈**，提示"反馈已提交，感谢帮助改进"。
3. 点踩后气泡下方显示"已点踩：分类"。管理员会在"badcase 管理"中跟进处理。

【截图：反馈问题（点踩）弹窗】

### 6. "来自缓存"标注

若你提出的问题与近期已有提问完全相同，系统直接返回先前的回答（更快、更省资源），气泡下方标注"来自缓存"。缓存回答与原回答内容一致、引用一致，可放心核对。管理员更新知识库后缓存会自动清空，此后同一问题按最新知识回答。

### 7. 会话管理

1. 点击左栏**＋ 新会话**开始一段新对话；首次提问若未建会话，系统会自动创建。
2. 会话默认以首问命题，列表按最近更新排序；点击条目切换，历史消息自动加载。
3. 鼠标悬停会话条目，点**删除**，确认框提示"删除后会话及聊天记录不可恢复，确认删除该会话？"，点击**删除**生效。
4. 点击右上角**退出**可安全退出登录。

## 第二篇 管理员篇

> 本篇面向试点管理员，覆盖知识库维护、用户与评测、运营治理的全部管理操作。侧边栏"知识库"与"管理"两组菜单仅管理员可见。

### 1. 知识库·文档管理

【截图：文档管理页】

列表列：标题（含 `v版本号` 与"降级解析"标注）、部门、状态、责任人、生效日期、操作。筛选行支持**部门 / 状态 / 标题关键字** + **查询 / 重置**；工具栏有**刷新 / zip 批量导入 / ＋ 上传文档**。

#### 1.1 上传文档（三要素 + 合规勾选）

1. 点击**＋ 上传文档**，第 1 步选择文件：仅支持 pdf / docx、≤50MB，`.doc` 会被拒收并提示"另存为 docx 后上传"。
2. 点**下一步**进入元数据表单，三项必填 + 一项合规勾选：
   - **标题**（自动按文件名预填，建议按"部门_主题"命名）；
   - **部门**：客服 / 人力 / 全员——决定谁能检索到它；
   - **责任人** 与 **生效日期**；
   - **合规确认**：必须勾选"我确认本文档为试点部门人人可读，无涉密内容"，否则无法入库。
3. **到期日期**选填：填写后到期自动下线。
4. 点击**提交入库**，提示"已加入解析队列"。完全重复的文件会被查重拦截并指向已有文档；近重复或疑似含敏感信息的文档入库后标"待确认"，需你在操作列点**确认激活**才参与检索。

#### 1.2 状态机：pending → parsing → ready / failed

| 状态 | 含义 | 你要做什么 |
|------|------|-----------|
| ◔ 排队中 | 已入库，等待解析 | 等待 |
| ◐ 解析中 | 解析进行中（列表每 30 秒自动刷新） | 等待 |
| ● 就绪 | 解析完成、参与检索 | 无 |
| ✖ 失败(悬停看原因) | 解析失败，悬停显示具体原因 | 按原因处理后点**重试** |

#### 1.3 失败重试与降级解析

- **重试**：仅"失败"行出现**重试**按钮，点击后提示"重试已提交，文档重新进入解析队列"。常见失败原因：疑似扫描件或空文档、格式损坏——先修复源文件再重试。
- **降级解析**：pdf 走 MinerU 高精度解析，服务不可用时自动降级为纯文本提取并在标题旁标注"降级解析"——内容仍可检索，但表格/版面信息可能不完整，建议关注。

#### 1.4 zip 批量导入

点击**zip 批量导入**，选择压缩包后点**开始导入**。条目须为 pdf / docx；文件名按 `部门_主题_日期` 命名可自动补元数据，否则该条目标为"元数据待补"（跳过待补），需要你随后逐份补传。导入完成后弹窗给出逐文件结果（已入库 / 重复跳过 / 已拒绝 / 元数据待补）与汇总。

> 删除文档暂未开放（按钮置灰提示"暂不支持"）；文档更新通过上传新版本完成，版本号自动递增，旧版本自动归档。

### 2. 知识库·问答对管理

【截图：问答对管理页】

问答对（FAQ）命中后整条注入回答，优先级高于文档检索。

1. **建模板**：点**下载导入模板**，Excel 含三列：问题 / 答案 / 状态（enabled·disabled，空缺省启用）。限 ≤5000 行，问题 ≤2000 字、答案 ≤10000 字。
2. **导入**：点**Excel 批量导入**，选择文件后点**开始导入**。导入是**整批校验**：任一行不合格整批退回、全部不入库，弹窗列出"行号 / 字段 / 错误原因（中文）"，修正后点**重新导入**。成功提示"导入完成：本批 N 条问答对已入库并向量化，批次号 …"。
3. **启停**：表格"启用"列开关即时生效，提示"已启用，立即参与匹配"或"已停用，立即退出匹配"。停用适合答案过时待修的条目。
4. **编辑**：点**编辑**修改问题与答案，保存后问题重新向量化、新答案立即生效。
5. **删除**：点**删除**，确认"确认删除该问答对？"后软删退出检索。

### 3. 检索测试（两套分数含义）

【截图：检索测试页】

上线前用"检索测试"验证检索效果：选**部门范围**（客服 / 人力 / 全员），输入测试问题，点**测 试**。

结果分两段，**两套分数口径不同、不可互比**：

- **问答对命中**：显示"FAQ-N 相似度 X ✓ 超阈值(T)，将整条注入"。相似度是问题的向量余弦，超过问答对阈值即整条命中；若无超阈值命中则提示"无超阈值命中 → 走文档检索链路"。
- **文档块命中（top20 → 重排 top5）**：表格分列展示**重排分数（sigmoid）**与**召回余弦**——召回余弦是向量召回阶段的相似度（决定候选排序），重排分数是精排模型给出的相关性分（决定最终顺序），二者来源不同。每块标注"✓ 超阈值 / 低于阈值 / 已折叠"。
- 底部展示"当前生效阈值：问答对 X · 拒答 Y（只读，随检索测试响应下发）"。

> 空结果提示"未命中任何问答对或文档块"：先确认文档已导入且状态为"就绪"。

### 4. 用户管理（发放一次性密码）

【截图：用户管理页】

1. **发放账号**：点**＋ 新建用户**，填写**用户名**（2-32 位，支持中文、字母、数字）、**部门**，选**角色**（成员 / 管理员），点**创建并生成初始密码**。
2. 弹出"初始密码（仅此一次展示）"对话框：按警示"请立即复制并发送给用户，关闭后不可再查看；用户首次登录将被强制改密"，点**复制**发给用户，点**我已保存**关闭。关闭后密码不可再查看，遗失只能重置。
3. **禁用 / 启用**：操作列点**禁用**（确认"禁用后该账号立即失效，确认？"），该账号立即无法登录；**启用**恢复。不能禁用自己。
4. **重置密码**：操作列点**重置密码**（确认"重置后将生成新的初始密码（一次性展示），确认？"），生成的新初始密码同样仅展示一次；重置同时解除锁定并强制用户首登改密——这也是"忘记密码"与"账号锁定"的标准处理方式。

状态列三态：正常 / 已锁定 / 已禁用。

### 5. 评测管理

【截图：评测管理页】

#### 5.1 题库与跑分

1. "评测题库"页签：**下载模板** → 填写列：部门（中文名 客服/人力/全员）/ 问题 / 期望答案 / 来源 / 题型（factual·multi_hop·cross_reject，空缺省事实型）；**期望答案填 `[拒答]` 表示串库拒答题**。点**Excel 导入题目**上传，同样整批校验、错误行全量列出。
2. "跑分记录"页签点**发起跑分**：填**任务名称**、选**视角部门**，点**开始跑分**。检索范围恒为 [视角部门, 全员]；串库题按回答是否等于固定拒答话术自动判分。任务后台执行，状态"进行中"每 10 秒自动刷新，收口为"已完成"或"失败"。
3. 点**报告**打开跑分详情：config 快照（模型、提示词版本、阈值、topK/topN）、逐题明细（期望答案、回答、命中引用、自动/人工判定）、分组报告（总题数 / 加权得分 / 总体准确率 / 待判定，按部门与按题型）。

#### 5.2 人工录分

事实型与多跳题自动判定为"待判定"，需人工评判：

1. 在逐题明细点**评判**，"人工评判录分"弹窗展示期望答案与自动判定；
2. 三档单选：正确 / 部分正确 / 错误（折算口径：正确=1 / 部分正确=0.5 / 错误=0），点**提交判定**后正确率即时重算。

#### 5.3 阈值扫描

报告区点**扫描阈值曲线**，系统按多档拒答阈值 / 问答对阈值重放本次明细，给出曲线与推荐值（已排除"全员拒答"档）。注意口径注明：曲线 accuracy 为阈值重放口径，≠ 报告 accuracy，仅用于横向比较各档位；可点**复制扫描结果 JSON** 留档。调参需另行评审，本页面只读不下发。

### 6. 提问记录

【截图：提问记录页】

顶部提示"提问记录保留 90 天（天数可配置），仅管理员可见；调优使用前先脱敏"。

1. 筛选：**部门 / 日期范围 / 反馈（有点踩 / 无点踩）**，点**查询**。
2. 列表：时间、用户、部门、问题摘要（附回答类型：缓存 / 问答对 / 文档检索 / 拒答）、引用（有 / 无）、反馈（点踩 / 点赞）。
3. 点**详情**打开"提问详情（只读）"抽屉：提问原文、回答全文、引用 JSON、运行信息（token、耗时、缓存命中、是否拒答）与点踩备注——处理 badcase 前先在这里还原现场。

### 7. badcase 管理（处置："已忽略"必填理由）

【截图：badcase 管理页】

员工每条点踩都会进入 badcase 队列（状态"待处理"）。列表默认筛"待处理"，支持按部门 / 处理状态（待处理 / 已修语料 / 已忽略）筛选。

1. 点**处理**打开"处理 badcase"弹窗，选择处理方式：
   - **更新文档/补问答对**（状态"已修语料"）：备注选填，说明修订内容；
   - **忽略（说明理由）**（状态"已忽略"）：**必须填写理由**（1-500 字，占位提示"忽略必须说明理由（1-500 字）"），空理由无法提交。
2. 点**提交**，提示"已处理"。处置为终态，不支持重开。

### 8. 运营概览与健康度

【截图：运营概览页】

1. 顶部**近1天 / 近7天**切换统计口径；四张统计卡：今日提问（近7天提问）、命中率（非拒答）、拒答率、点踩率。
2. "按部门"表：提问数、命中率、拒答率、点踩率、token 消耗。
3. "语料健康度"面板：
   - **文档就绪率**（就绪数/总数）进度条；
   - **待确认文档**：N 篇，点**去处理**直达文档管理确认激活；
   - **零召回文档榜**（近 30 天 0 命中）：点击行进入文档管理，评估是否更新或下线；
   - **待过期清单**（7 天内到期，含已到期未下线）：到期日标红提示尽快更新。

### 9. 审计日志（导出 CSV）

【截图：审计日志页】

1. 筛选：**操作人ID / 动作（精确匹配，如 user.create）/ 对象类型（如 qa_pair）/ 日期范围**，点**查询**。
2. 列表：时间、操作人、动作、对象、IP；点行首展开查看详情 JSON（只读）。
3. 点**导出 CSV** 按当前筛选口径导出；若行数超上限会提示"结果行数超出导出上限，文件已截断（仅含最近记录）"。审计日志只增不删，用于事后追溯。

## 第三篇 常见问题

### Q1 为什么我的问题被拒答了？

系统只依据知识库回答，检索不到足够相关的内容时固定回答"知识库中未找到相关内容"。这是防止编造的产品红线，不是故障。请换问法重试，或反馈管理员补充知识库（见第一篇第 4 节）。

### Q2 为什么回答显示"来自缓存"？

问题与近期提问完全相同，系统直接返回先前结果以加快响应。内容与引用与原回答一致；知识库更新后缓存自动清空（见第一篇第 6 节）。

### Q3 上传失败原因对照表

| 界面提示 | 原因 | 处理 |
|----------|------|------|
| "仅支持 pdf / docx 文件" | 扩展名不在白名单 | 转为 pdf / docx |
| ".doc 不支持，请另存为 docx 后上传" | 老格式 .doc 拒收 | 用 Word 另存为 .docx |
| "文件超过 50MB" | 超单文件上限 | 拆分或压缩文档 |
| "文件与已有文档完全重复（已有文档 ID N），如需更新请上传新版本" | SHA-256 精确查重命中 | 无需重传；更新内容则改文件后作为新版本上传 |
| 状态"✖ 失败(悬停看原因)"，如"疑似扫描件或空文档" | 解析质量红线拦截 | 提高扫描清晰度 / 换文字版文档后点**重试** |
| 标的"待确认" | 近似重复或疑似敏感信息命中异步预检 | 核对后点**确认激活**或放弃该版本 |
| zip 条目"元数据待补" | 文件名不符合"部门_主题_日期" | 重命名后重新打包导入 |

### Q4 账号被锁定，提示 15 分钟？

连续多次输错密码会触发 15 分钟锁定，锁定期间即使输对密码也会被拒绝。等待 15 分钟自动解锁，或联系管理员**重置密码**（重置会立即解除锁定）。

### Q5 忘记密码怎么办？

自己无法找回。联系管理员在"用户管理"中为你**重置密码**：管理员会生成一个新的初始密码（仅展示一次）发给你，你首次登录时会被要求修改密码。

### Q6 登录提示"请求过于频繁"或"每日提问次数已达上限"？

前者是登录限流，稍等再试；后者是每人每日提问配额用尽（默认 200 次），次日自动恢复。
