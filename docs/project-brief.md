## 一、一句话定位

为企业打造的 **RAG 知识问答工作台**：员工提问，系统基于部门知识文档与问答对回答并给出可核对的引用来源。当前建设双部门试点 MVP；**设计与规范按 100x 规格一次到位**（全员 2 万人 / 10 万文档 / 日 5 万提问），建设按触发线分期，到线零返工。

## 三、技术栈

FastAPI(Python 3.11) · Vue3+TS+Element Plus · PostgreSQL+pgvector（messages 月分区）· MinerU · TEI(BGE-M3/bge-reranker-v2-m3) · Docker Compose 单机（4核16G VM）· loguru · Alembic · pytest。
六个可替换接口：LLMProvider / VectorStore / Parser / Embedder+Reranker / FileStorage / AuthProvider（+预留 Connector、CacheProvider）。

## 七、里程碑

W1 脚手架+入库管道+同步预检（白名单+精确查重）+黄金样本+合规答案 → W2 问答 API+SSE+引用 → W3 知识库管理+解析后异步预检（敏感/乱码/近似）+到期下线+健康度看板+RAGFlow 基线 → W4 客服内测+管理后台+评测+zip 批量+元数据自动建议+阈值扫描 → W5 HR 接入+串库+恢复演练+知识缺口报告/chunk 召回统计 → W6 缓冲+验收。
**M10 工作量修正（二轮评审）**：全量约 8-12 人日，非 3 天。裁剪顺序（W5-W6 进度紧张时依次降级）：F-1011 → F-1010 → F-1012（简化为 3 档扫描）；**F-1001~1006/1009 为必做**。经裁剪机制守住 6 周周期，存在 ±3 天风险（详见 [mvp-design.md §10](archive/2026-09-28-mvp-design.md)）
