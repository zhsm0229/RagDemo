## 三、方法论沉淀（可复用）

1. **守账测试优先**：漂移集中在守账盲区（手工枚举行/双源引述）——凡"会漂的数字与文案"立守账用例，比人工核对可靠且一次投入永久生效
2. **核伪纪律**：评审发现先实测再实施（本轮核伪 2 条：F1 e2e 计数、超时行未同步；QC R1 实测更正设计失实）——评审员读旧 hunk/引错先例是常态，证据要 file:line
3. **jsdom 事件链先例**：ElButton/ElTag 经组件 emit 的 click 在 jsdom 不可靠 → 原生 button（三票复用）；模板引用未注入 handler 会**静默无效**（无报错），交互用例必须配行为断言
4. **拆分模板**：超 300 行红线=门面+子模块+`__all__` re-export（导入路径零改动），monkeypatch 目标随实现迁、断言零改动；切割脚本化防转录错，但**脚本异常中断会留半成品**（工单 30 handler 缺失事故）——落盘后必跑导入冒烟
5. **跨平台脚本坑**：BSD/GNU date 语法分叉（age 计算 python 化）；compose ports 追加合并语义（覆盖文件 `!override` 钉端口）；git `text eol=lf` 会损坏二进制（PNG 魔数含 0d0a）——`*.png binary` 白名单必备
