## 三、P1 修复摘要（30 项，按主题归并）

**数据层**：messages 补 updated_at/user FK/badcase_status/answer_type/is_eval + DEFAULT 分区；audit_logs 主键改 (id, created_at)（未来分区前置条件）；eval_runs 加 status + config 阈值快照；citations 结构改 {n, refType, refId, ...}（qa_pair 引用可定位）；sync_sources 加 hr_system 类型；文档版本识别不含版本/日期词（命名规范注记）。

**架构与演进**：messages 分区建成时点三处统一为"MVP 即建成"；A 阶段动作补"FileStorage 切共享存储"（多实例前提）与"黑名单/缓存迁 Redis"；TaskQueue 抽象补入接口清单；scaling-plan "第二个部门"措辞修正；"六层"表述统一为五层。

**API 与管道**：SSE 四事件补完整 DTO 字段表（citations 先行、done 含 refused/cacheHit/tokens、error 含 retryable，重试语义=新消息）；检索分数口径全局定义（余弦相似度 vs sigmoid 归一化 rerank 分，阈值不混用）；问答对匹配补 status='enabled'；F3 补检索为空分支、error/断流分支、改写失败降级、query 向量一次复用；F5 评测旁路缓存 + is_eval；F6 登录成功清零计数；F7 并发互斥/排队。

**安全与运维**：RAGFlow 基线环境禁配云 API 真实语料（§7.6）；zip 解压上限防炸弹（§6.3）；依赖 hash 固定（§6.6）；登录限流实现方案（§5.4）；登出黑名单方案明确（§5.3）；端口发布约束（仅 app 发 80，§12.2）；PG 15+ 版本钉死；备份目录权限与 .env 托管（§18）；RPO≤24h/RTO≤2h；发布记录镜像 digest + 回滚三红线（新列可空/枚举演进配降级/换模型回退重建索引）；CI 冒烟用 Parser stub；每用户每日 200 次提问上限（§17.5）；质量红线分母定义（§10.3）。

**产品与流程**：串库用例双向化（每向 ≥10 题 + 全员对照组，§15.6）且所有 MR 必跑（§20.2）；brief 待办表加"最晚到位"列；W1 拆最小集（HR 规整类先行）；里程碑表加外部依赖列；风险表补资源挤兑；M9 补 IM bot/Agent/Excel 表格知识二期落点；用户名规则改 2-32 位允许中文（§21.5，内部账号中文名常态）；hard指标 #7 非功能基线（压测判据 p95+0 错误）。

**界面与原型**：P7 提问记录部门硬编码 bug 修复（会话带 dept）；输入法回车误发守卫；用户可见文案清除全部条款号/黑话；引用面板可折叠；全库重建加红色确认框；删除被评测引用文档拦截；新增成功回第 1 页；会话活跃置顶；问答对补更新时间列+编辑弹窗；评测报告补回答与命中引用；用户页补锁定状态与解锁；审计页查询接线；P3/P4 空状态引导；发送按钮 tooltip 覆盖所有禁用原因；ui-spec 页面清单补 P11 审计日志。

**测试**：验收判定协议（见 P0-8）；F-803 短 TTL 验证；F-601 拒答期望格式；F-602 config 快照；F-302 质量红线口径统一。

**P2 处置**：39 项 P2 中 31 项随上述修复一并落实；8 项登记为原型豁免或低优先改进（见 [deviations.md](ui-mockups/deviations.md)：Options API、内存分页、自绘统计卡、CSS 条形图、手写校验、模拟流式、硬编码色值、内容区宽度）。
