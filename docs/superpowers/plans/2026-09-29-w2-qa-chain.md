# W2 问答链路 实施计划（TDD）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 W2 增量——RAG 问答全链路（问答对优先匹配 → pgvector 检索 → 重排折叠 → prompt 组装 → SSE 流式生成 → 引用/落库/反馈）+ W1 移交清欠 + TEI/OpenAI 兼容真实现激活。

**Architecture:** 延续 W1 五层单向依赖 `api → services → rag → core → db`。检索编排放 `services/retrieval.py`（查库 + Embedder/Reranker 注入），prompt 组装为 `rag/prompt.py` 纯函数，问答编排 `services/chat.py` 只产出事件计划与终结写库，SSE 细节归 `api/chat.py`。LLM/向量三件套经 `core/assembly.py` 装配：`test_mode → Stub`，否则 TEI + OpenAI 兼容实现（云 GLM-4 与内网 vLLM Qwen 同一实现，合规轨道切换只改 `.env`，§7.1）。

**Tech Stack:** 沿用 W1（FastAPI/SQLAlchemy 2.0/pgvector/pytest+httpx）+ httpx（TEI 与 OpenAI 兼容客户端，测试用 httpx MockTransport，不新增重库）。

## Global Constraints（摘自 standards.md v1.7 与 flows.md F3，逐条适用于每个任务）

- 分数口径 §4.4（**两套分数不得混用阈值**）：问答对阈值 0.85 作用于 **embedding 余弦相似度 = 1 − `<=>` 距离**；拒答阈值 0.55 作用于 **reranker sigmoid 分数**
- 检索 SQL **强制 JOIN documents 并过滤 `documents.is_active AND documents.status='ready'`**（W2 强制移交项①；仅 chunk.is_active 会泄漏待确认/归档内容）；全部查询 `dept_id IN (用户部门, 全员)`（F-502，串库 0 容忍）
- SSE 四事件 `citations`（**先于 token**）/`token`/`done`/`error`，DTO 字段逐字按 §3.6 表；错误事件 `{code, message(中文脱敏), retryable}`
- 拒答话术**精确**为常量 `知识库中未找到相关内容`（F-203/CHAT-03，citations 为空、done.refused=true）
- Prompt 安全 §17.5/§6.7：系统三原则；资料统一 `<data>` 包裹声明不可信；引用编号程序生成；用户问题只经 user role；max_tokens 服务端 clamp（默认 4096）
- LLM 调用超时 chat 60s / embed+rerank 10s，失败重试 1 次；上游故障统一 `UpstreamError`（`broken=True` = 已产出部分内容）；对外脱敏"生成服务暂时不可用"（§6.8）
- 精确缓存 §17.5：TTL 5min，键 = 部门 + **规范化后的问题**（多轮用改写后问题作键）；命中标注 `cacheHit`；拒答**不写缓存**（保真 F-1010 拒答案频统计）；每用户每日提问上限 200（可配）
- SQL 一律参数绑定；`SET LOCAL hnsw.ef_search` 的值用 `psycopg.sql.Literal` 组合（禁 f-string 拼接）；Alembic 迁移仅追加
- 写库测试必须读回断言（§15.4）；断言精确禁 `A or B`（§15.5）；单文件 ≤300 行、函数 ≤50 行；ruff lint+format 全绿
- 提交：Conventional Commits，且一律 `git commit -m "..." -- <本任务文件>`（W1 账本规矩，防 swept commit）
- 本机无 make：验证命令一律 `.venv/Scripts/python -m <module>` 直等
