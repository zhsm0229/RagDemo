# W4 前端冲刺+后端尾巴 实施计划（TDD）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 W4 增量——**Vue3 前端全页面（P1-P11，严格对照交互式原型）** + 后端尾巴（用户管理 F-102、审计查询 F-802、zip 批量 F-1007、元数据自动建议 F-1008、阈值扫描 F-1012 简化版、documents ILIKE 转义）。完成后系统可进入客服内测。

**Architecture:** 前端为独立 `frontend/` 工程（Vite+Vue3+TS+Element Plus），同构双车道中**前端单道串行**（路由/共享组件强耦合，并行必冲突），后端尾巴一道并行；评审流水线照 W3 模式。前端经 Vite 代理同源访问后端（JWT httpOnly Cookie 天然可用），SSE 用 fetch+ReadableStream（§3.6，无 EventSource）。

**Tech Stack:** Vue 3.5+ `<script setup>` TS / Element Plus（钉版本）/ Vite / vue-tsc / Vitest+@vue/test-utils / ESLint+Prettier / 后端沿用 W1-W3。

## Global Constraints（standards.md v1.7 前端条款 + W3 账本交接，逐条适用于每个任务）

- **§8.7 严格对照原型（强制）**：`specs/ui-mockups/html/index.html` 是唯一基线——开发前通读对应页面完整实现，逐字段/逐控件/逐交互核对；原型的每个 tab、卡片、按钮、表格列、表单字段必须全部体现，禁止省略合并改布局；任何偏差登记 `specs/ui-mockups/deviations.md` 并说明理由
- **§8 界面规范**：Element Plus 唯一组件库（禁第二套 UI 库）；术语表唯一（§8.3 知识库/文档/问答对/引用/重建索引/评测/点踩/部门/预检/健康度/零召回/知识缺口/阈值扫描/到期日期）；异步操作 loading/成功/失败三态；空态给下一步引导；文案中文说人话；只读置灰（纯展示 disabled/纯文本，需复制的用 readonly 保留选中）；接口字段逐字段核对（§8.9，或从 /openapi.json 生成）；基础数据禁止空表（§8.10）
- **§9 布局**：侧边导航+顶栏+内容区；member 登录默认问答页且**不显示管理导航**；内容区最大 1200px 居中；问答页左右两栏（会话列表+对话区）；间距 8px 基数；圆角阴影颜色取 CSS 变量禁硬编码；1280px+ 桌面端
- **§21**：前端校验只为体验，后端唯一权威；校验器收敛 `src/validators/` 单一模块（必填失焦即校验、空值由必填规则处理）；提问 1-2000 去首尾空白；**对任何用户输入禁用 v-html**（XSS §21.7）
- **§22 列表弹窗**：查询条件与"查询/重置"同行；服务端分页 10/20/50/100 默认 20 右对齐含总条数；默认创建时间 DESC；弹窗 `:close-on-click-modal="false"` 保留 Escape；提交失败内联弹窗不关；新增回第 1 页、编辑/删除保持当前页（删空回退）
- **§3.6 SSE**：POST /api/chat/stream 用 fetch+ReadableStream 消费；事件 citations（先于 token）→token→done→error；**重试=重新发起请求生成新消息**，断流提示可重试
- **§2.2**：`<script setup>` 组合式 TS；ESLint+Prettier；**禁止 any**（确需注释原因）；生产构建剥离 console.log
- W3 交接：评测 detail 轮询容错（running 无 pendingCount、failed 无 pendingCount）；badcaseStatus"待处理"默认视图由前端显式传参；两套分数（qa.similarity / docs[].rerankScore）不得互比；'已忽略'处置必填理由（ADM-03）；点踩必填分类+备注（CHAT-09 后端 422 兜底）
- 后端任务沿用既有规范（参数绑定/审计/AdminUser/读回断言/迁移仅追加/TDD）；提交 pathspec 限定；`.venv/Scripts/python -m` 直等命令；**工作区有用户预存改动（.env.example/project-brief.md staged）——任何任务不得触碰**
