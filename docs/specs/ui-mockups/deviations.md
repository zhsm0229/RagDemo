# 界面原型偏差登记表（deviations）

> 依据 standards §8.7：实现与原型基线的任何偏差只能登记在此并附理由。本表登记**交互式 HTML 原型**（html/index.html）相对正式实现要求的已知豁免项——原型是交互/字段/布局基线，不是代码风格基线。

| 1 | 组件组织方式 | Options API + 字符串模板（无构建） | `<script setup>` 组合式 API + TS（standards §2.2） | 原型零构建双击可开；对照基线限定为交互/字段/布局，不含代码风格 |
