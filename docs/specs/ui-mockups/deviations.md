# 界面原型偏差登记表（deviations）

> 依据 standards §8.7：实现与原型基线的任何偏差只能登记在此并附理由。本表登记**交互式 HTML 原型**（html/index.html）相对正式实现要求的已知豁免项——原型是交互/字段/布局基线，不是代码风格基线。

| # | 偏差 | 原型做法 | 正式实现要求（依据） | 理由 |
|---|------|---------|--------------------|------|
| 1 | 组件组织方式 | Options API + 字符串模板（无构建） | `<script setup>` 组合式 API + TS（standards §2.2） | 原型零构建双击可开；对照基线限定为交互/字段/布局，不含代码风格 |
| 2 | 分页与筛选 | 前端内存分页/筛选 | 服务端分页（standards §22.1，pageSize 上限 100） | 演示数据量小；正式实现数据流不同 |
| 3 | 概览页统计卡与图表 | 自绘 .stat-card + CSS 条形图 | el-statistic / 图表组件（standards §8.1 组件库约束） | 避免引入 echarts 依赖；布局结构一致 |
| 4 | 表单校验 | 手工 if 校验 | Element Plus rules 声明式 + 失焦校验（standards §21.3） | 演示简化；校验规则口径已与 §21.5 一致 |
| 5 | 流式回答 | setInterval 逐字模拟 | fetch ReadableStream 消费 SSE（standards §3.6） | 无真实后端；事件时序（citations 先行）已按契约演示 |
| 6 | 样式硬编码 | head 内少量硬编码色值 | 主题 CSS 变量（standards §9.3） | 原型独立于构建体系；正式实现走主题定制 |
| 7 | 内容区宽度 | 未强制 1200px 居中（仅 P5 局部） | 1200px 居中（standards §9.2） | 问答页三栏布局在 1280px 下优先利用空间，实现时按 §9.2 |
| 8 | M10 部分新界面未入原型 | 阈值扫描（P9）与知识缺口卡（P10）仅 ui-spec 文字描述 | 正式实现按 ui-spec §八 文字规格（含二轮补充的实现约束） | 二轮设计师判定：文字描述足以评审；预检结果展示、健康度概览条、到期日期字段已补进原型（高交互风险项必须可视） |
| 9 | P1 登录页演示提示区（demo-tip） | 登录卡片底部展示演示账号提示（admin/客服小王/新员工小李，密码统一 123456） | 正式实现不渲染 demo-tip | 原型为纯前端演示数据（原型头部已自注"无真实后端"）；生产无这些账号，保留会误导用户并暴露演示口令（task-7 裁决） |
| 10 | 首登改密形态 | P1 内弹出不可关闭 el-dialog（"首次登录请修改密码"，420px） | 独立路由 /change-password 改密页（ui-spec §九：独立路由，守卫白名单外全拦截不可绕过） | ui-spec 与原型形态不一致处，按规格基线执行；路由形态支持刷新/直达/守卫拦截，T6 已预留该路由 |
| 11 | 改密表单字段 | 仅 新密码/确认密码 两个字段 | 增加"原密码"必填字段 | 后端契约 POST /api/auth/change-password 必填 old（docs/api.md §2.2，验旧密码即身份证明）；原型无后端故省略 |
| 12 | 改密页副标题 | 原型对话框无副标题 | 卡片副标题展示"当前账号：{username}" | 独立页无顶栏身份信息，标明改密账号防误操作；不改变原型字段与交互 |
| 13 | 登录/改密按钮 loading 态 | 无 | 提交期间按钮 loading 并拦截重复提交 | 原型无真实后端、无重复提交风险；正式实现防连点，按钮视觉样式不变 |
| 14 | 会话删除二次确认控件 | el-popconfirm 行内气泡（"确认删除该会话？"） | ElMessageBox.confirm 模态确认（task-8 约定，F-207） | 模态确认文案可承载"删除后不可恢复"警示，信息层级更高防误删；确认/取消语义与原型一致 |
| 15 | 消息 meta 的 token 用量展示 | "token: in x / out y · ms" 逐条展示 | 不在气泡 meta 展示 token/耗时 | 会话历史接口（docs/api.md §3.4）无 token 字段，展示将造成流式与历史渲染口径不一致；用量已消息级落库（F-209），P7 提问记录详情可查 |
| 16 | 点踩/点赞与"查看原文"核对弹窗 | 气泡 meta 👍/👎 + 点踩弹窗；点引用卡弹原文 el-dialog | 未随 task-8 交付，属 T9（F-208 反馈、F-202 引用溯源完整交互） | 引用 DTO 无正文 chunk 字段（docs/api.md §3.1），原文弹窗需与 T9 一并定契约；本任务已交付角标可点 + 面板滚动/高亮联动 |
| 17 | 拒答文案 | "知识库中暂无相关内容。建议换个问法…"（演示文案） | 精确话术"知识库中未找到相关内容"（token 逐字下发，F-203 验收红线） | 拒答话术是产品红线（禁编造），后端 REFUSAL_TEXT 逐字流式下发，原型演示文案与之不一致处按红线执行；气泡 meta 保留"已拒答"标注 |
| 18 | 进入问答页默认选中最近会话 | 无会话选中，默认停在空态 | 进入即拉取列表并选中最近会话渲染历史（列表 updated_at 降序首条） | P2 为默认首页，员工回访场景直接续上次问答；无会话时仍展示原型空态引导 |

> 以上豁免仅适用于评审用原型；正式实现不得引用本表作为偏离规范的依据。
