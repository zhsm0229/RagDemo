```
┌──────────────┬──────────────────────────────────────┬──────────────────┐
│ 会话列表      │  对话区                               │ 引用面板(可折叠)   │
│ [+ 新会话]    │ ┌──────────────────────────────────┐ │ ┌──────────────┐ │
│──────────────│ │ 用户: 报销标准是多少？              │ │ │ [1] 客服手册   │ │
│ 报销标准问答   │ └──────────────────────────────────┘ │ │  第3页         │ │
│  09-28 14:20 │ ┌──────────────────────────────────┐ │ │ 第3章>3.2 标准  │ │
│──────────────│ │ 助手: 根据资料[1]，报销标准为…      │ │ │ 相似度 0.91    │ │
│ 产品参数咨询   │ │    …（逐字流式，光标闪烁）          │ │ ├──────────────┤ │
│  09-28 13:05 │ │                                    │ │ │ [2] FAQ问答对  │ │
│──────────────│ │ [1][2] 来自缓存 · 👍 👎            │ │ │ 相似度 0.88   │ │
│ （软删hover） │ └──────────────────────────────────┘ │ └──────────────┘ │
│              │ ┌────────────────────────[发送]────┐ │                  │
│              │ │ 输入问题… (1-2000字, 字数统计)     │ │                  │
│              │ └──────────────────────────────────┘ │                  │
└──────────────┴──────────────────────────────────────┴──────────────────┘
```

**组件映射**：布局 el-container；会话列表 el-menu + 自定义项（悬浮显示删除）；消息区自定义气泡；流式用 fetch stream 消费 SSE；引用面板 el-card 列表；反馈 el-button + el-dialog。

**交互与状态**：
| 交互 | 规范依据 | 行为 |
|------|---------|------|
| 点角标 `[n]` | §8.2 kotaemon 模式 | 右侧面板滚动到对应引用卡并高亮；卡内"查看原文"弹 el-dialog 展示 chunk 全文 + 文档名 + 页码 + 标题路径 |
| 点踩 | §8.2 MaxKB 模式 | el-dialog：分类单选（答案错误/引用无关/拒答不当/其他）+ 必填备注；失败错误内联弹窗内不关闭（§22.2） |
| 流式中断 | §16.3 | 显示"生成中断，请重试"，可重发原问题 |
| 拒答 | F-203 | 正常气泡样式展示"知识库中未找到相关内容"，无引用角标 |
| 缓存命中 | F-205 | 消息底部灰色小字"来自缓存" |
| 输入校验 | §21 | 失焦校验空值；超 2000 字即时提示并禁用发送 |
| 会话删除 | §22.3 | el-popconfirm 二次确认，软删后从列表消失 |

## 三、P3 文档管理（RAGFlow 模式，§8.2）

```
┌─ 知识库·文档 ────────────────────────────────────────────────┐
│ [部门▾] [状态▾] [关键字____] [查询] [重置]      [+ 上传文档]   │
│──────────────────────────────────────────────────────────────│
│ 标题              部门  版本  状态        责任人  生效日期  操作 │
│ 客服_退货政策_v2   客服  v2   ● 就绪      张三   2026-01  引用块·重建·删除│
│ 客服_话术手册      客服  v3   ◐ 解析中 45%  李四   2026-03  ·     │
│ HR_考勤制度_v1    人力  v1   ✖ 失败(疑似扫描件) 王五 2025-12 重试·删除│
│──────────────────────────────────────────────────────────────│
│                              共 128 条  < 1 2 3 >  10/页▾    │
└──────────────────────────────────────────────────────────────┘
```

**上传对话框**（el-dialog，禁遮罩关闭 §22.2）：
1. 选择文件（dragger，白名单即时校验，.doc 即时拒收提示 §10.1；支持 zip 批量，F-1007）
2. **同步预检结果**（提交前展示）：精确查重 ✓/✗、白名单校验结果——完全重复红字阻断（指向已有文档）
3. **解析后异步预检结果**（列表状态与文档详情展示，不阻塞上传）：近似重复（黄色"待确认"，确认后激活 F-1002）、敏感信息（黄色"待确认"：脱敏入库/拒收，列出到位置 F-1006）、乱码/质量红线（红色失败可重试 F-1005）。**三态机：绿=通过自动入库；黄=警示需管理员确认；红=拒绝仅可重选文件**
4. 元数据表单：标题、部门（下拉，默认管理员所在部门）、责任人（必填）、生效日期（必填）、到期日期（选填，F-1004）——文件名规范时自动预填（F-1008）
5. 合规确认 el-checkbox："我确认本文档为试点部门人人可读，无涉密内容"（必勾，§7.4；zip 批量逐文件落审计，runbook 写明抽查义务）
6. 提交后对话框关闭，列表出现解析中行

**健康度概览条**（表格上方，F-1009）：文档总数 / 就绪率 / 重复率 / 零召回文档榜入口 / 待过期清单入口。**红色触发条件：零召回文档 >0 即红、待过期 ≤7 天即黄、重复组 >0 即黄**；红色/黄色数字可点击过滤列表。

**状态列**（对应 F-302 状态机）：`● 就绪 / ◐ 解析中(进度%) / ✖ 失败(悬浮显示中文原因, [重试]) / ◔ 排队`；降级解析在状态旁加灰色 tag"降级解析"。

**版本历史**：行展开或"历史"弹窗，列出归档版本（只读置灰 §8.8，可查看不可改）。
**删除**：el-popconfirm；引用中（评测题 source_ref 指向）时阻止并提示 §23。
**重建索引**：文档级行操作 + 工具栏"全库重建"（el-alert 红色确认框）。

## 四、P4 问答对管理

- 工具栏：`[部门▾] [状态▾] [关键字] [查询] [重置]` + `[Excel 导入]` `[下载模板]`
- 列表列：问题 / 部门 / 状态(el-switch 启停) / 批次 / 更新时间 / 操作(编辑·删除)
- **导入向导**（3 步 el-steps 对话框）：① 选文件 → ② 校验报告（成功 N 行；错误行表格：行号+原因，全红可滚动）→ ③ 确认导入（有错误行时按钮禁用并提示修正后重新上传，整批校验 §21.6）
- el-switch 启停即时生效（F-402），变更写审计

## 六、P6 用户管理

- 列表：用户名 / 部门 / 角色 / 状态(正常·锁定至xx·已禁用) / 最近登录 / 操作
- 新建对话框：用户名 + 部门 + 角色 → 成功后弹**初始密码一次性展示**（readOnly 置灰可复制 §8.8 + [复制]），关闭后不可再看
- 操作：禁用/启用（popconfirm）、重置密码（同一次性展示）、解锁
- 全部操作写审计（F-801）

## 七、P7 提问记录 / P8 badcase

**P7**：筛选（部门/日期范围/是否有点踩）+ 列表（时间/用户/部门/问题摘要/是否有引用/反馈）+ 详情抽屉（完整对话、引用 json、token 用量、耗时；内容只读置灰）。保留策略提示条："记录保留 90 天"（§7.3）。
**P8**：列表（时间/部门/问题/反馈分类/处理状态 tag）+ 详情 + 处理动作（标记已修语料/已忽略 + 备注）。筛选默认"待处理"。

## 八、P9 评测管理 / P10 运营概览

**P9**：题库 tab（列表+Excel 上传，同 P4 向导模式）+ 跑分记录 tab（[发起跑分] 选部门范围；列表：名称/模型/提示词版本/总数/准确率/时间）+ 报告详情（分部门分题型准确率表；每题可展开：回答、命中引用、人工判定 radio[正确/错误/拒答正确]）+ **[阈值扫描]**（F-1012：拒答阈值 0.40-0.70 步长 0.05、问答对阈值 0.75-0.95 步长 0.05；**实现约束：复用同批生成结果仅后处理变阈值，不做多次真实调用**；推荐值=满足拒答率 ≤15% 的最高准确率点；[写回 P5] 一键应用并留审计）。
**P10**：四张 el-statistic 卡（今日提问/命中率/拒答率/点踩率）+ 按部门 token 消耗 el-bar-chart（数据源 llm_usage_daily 物化视图，≤5 分钟延迟）+ 最近 badcase 摘要列表 + **知识缺口卡**（F-1010：本周拒答问题 Top 榜，一键导出给对接人）。

## 九、P1 登录页

居中卡片：系统名 + 用户名/密码 + 登录按钮。错误内联显示（§22.2）。锁定提示明确到时刻。首登强制改密页：独立路由 /change-password，不可绕过（守卫白名单外全拦截）。

## 十、全局布局与规范对照

- 整体框架：侧边导航（member 仅见"问答"；admin 见全部）+ 顶栏（用户名/部门/退出）+ 内容区 1200px（§9）
- 术语表 §8.3 全页面统一；空状态带引导 §8.5；三态反馈 §8.4
- 全部列表页遵守 §22.1（查询条件同行、重置回第 1 页、默认创建时间降序、分页 10/20/50/100 默认 20）
- 全部弹窗 `:close-on-click-modal="false"`，失败错误内联（§22.2）
- CRUD 后刷新规则 §22.3；提交前自查 §23.1 逐项过

## 十二、交互式 HTML 原型（本规格的可执行版本）

**位置：[html/index.html](html/index.html)（连同 `html/lib/` 本地组件库，双击 index.html 即可打开，无需联网和构建）**

- 技术基座与正式实现同源：Vue 3 + Element Plus 2.8（本地化 CDN 文件），即"所见即所用的组件"
- 覆盖 P1-P10 全部页面，可操作：登录/锁定/首登改密、流式回答演示（逐字输出 + 引用角标联动 + 原文核对弹窗）、点踩弹窗、文档上传对话框（.doc 拒收、合规勾选）、解析状态机模拟（pending→parsing→ready）、问答对整批校验向导（含错误行报告）、用户创建（初始密码一次性展示+复制）、评测跑分与报告、审计联动
- 演示账号：`admin`（管理员，全部页面）/ `客服小王`（成员，仅问答页）/ `新员工小李`（首登强制改密演示），密码统一 `123456`
- 演示问句：`差旅报销标准` / `退货流程` / `保修` / `年假`（命中回答）；其他输入演示拒答；**同一问题重复提问演示缓存命中标注**
- 原型即 §8.7 所指"原型基线"的可交互形态；正式实现与本原型/本规格的偏差照旧登记 deviations.md
- 已知简化（不算偏差，实现时按规范做）：无真实后端与 SSE（用定时器模拟流式）、多轮问题改写未演示、鉴权仅前端模拟、提问记录保留策略仅提示条
