# 功能测试用例集 v1.1（待评审）

> 来源追溯：每条用例标注来源（F-ID = features.md 功能编号 / F# = flows.md 流程节点 / §x = standards 条款）。
> 优先级：**P0** = 冒烟用例（MR 流水线跑 CI 可自动化部分 + 发布必过档，进 CI §20.2）；**P1** = 核心功能（里程碑收口全量回归）；**P2** = 边界与体验（手工清单）。**NFR 类执行环境=部署机**（发布门禁/收口档），不在每-MR CI 内。
