## 验收判定协议（W3 前与对接人确认并冻结，验收硬指标 #1/#2/#4 的执行依据）

1. **准确率评判 rubric**（对应硬指标 #1）：
   - **正确**：回答与期望答案语义一致（要点全命中），且引用支持该结论 → 计 1 分
   - **部分正确**：命中 ≥一半要点但有关键缺失或表述歧义 → 计 0.5 分
   - **错误**：要点缺失/事实错误/**引用与结论无关或指向错误出处** → 计 0 分
   - 总分 =（正确 + 0.5 × 部分正确）/ 题目总数，≥80% 达标
   - 评判人：开发 + 试点对接人**双人独立评判**，不一致题由对接人终审仲裁
2. **引用覆盖率操作定义**（对应硬指标 #2）：含数字、日期、专有名词的句子视为事实断言，必须带 `[n]` 角标——脚本机检 + 人工抽检 20%
3. **"0 编造"判定**（对应硬指标 #4）：期望=拒答的题（eval_questions.qtype=cross_reject 或 expected 填 `[拒答]`），回答命中标准拒答话术（"知识库中未找到相关内容"）且无事实断言 → 自动判过；未命中的**100% 人工复核**判定是否编造

## 验收硬指标汇总（4-6 周里程碑评审用）

1. 客服、HR 各 30-50 道真实高频题，**分部门回答准确率 ≥ 80%**（人工评判，评测报告为证）
2. 含事实断言的回答**引用覆盖率 100%**，点开可核对原文（文档名+页码）
3. **串库用例 100% 拒答**——双向（HR 题 × 客服账号、客服题 × HR 账号），每向 ≥10 题，另配全员可见内容对照题组
4. 知识不足时 0 编造（拒答类用例按判定协议第 3 条执行）
5. 黄金样本集解析回归全部通过；RAGFlow 基线对照报告产出（同题集准确率差值；**基线显著优于自研时触发决策评审：补齐差距项或重估自研范围**）
6. 全部管理动作审计可查；规范手册自查清单（§23）逐项通过
7. **非功能基线**：首 token < 3s；检索链路 < 1.5s；20 并发会话压测（p95 首 token < 3s 且 0 错误）；文档上传 50MB 解析完成 < 5min
